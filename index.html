De un Excel de 20 años a una aplicación en producción From a 20-year-old Excel to an application in production

ProblemaProblem
Una competencia familiar de larga data se administró durante dos décadas en un solo Excel. Una sola persona podía mantenerlo, la lógica no estaba documentada y el archivo empezó a romperse a medida que el grupo crecía. A long-running family competition was managed for two decades in a single Excel file. Only one person could maintain it, the logic was undocumented, and the file started breaking as the group grew.
Qué hicimosWhat we did
Hicimos ingeniería inversa de la lógica de puntuación y la validamos contra veinte años de datos históricos: 30 de 30 casos reales con coincidencia exacta. Después la reconstruimos como una aplicación web con autenticación y base de datos. We reverse-engineered the scoring logic and validated it against twenty years of historical data: an exact match in 30 of 30 real cases. Then we rebuilt it as a web application with proper authentication and a real database.
Lo difícilThe hard part
La aplicación soportó carga real en producción, con todo el grupo usándola al mismo tiempo, sin perder un solo dato. The application survived real production load, with the whole group using it at once, without losing a single record.
ResultadoResult
El grupo completo migró fuera de la hoja de cálculo. El proceso ya no depende de una persona: vive en un sistema que cualquiera puede usar y que se puede mantener. The entire group migrated off the spreadsheet. The process no longer depends on one person: it lives in a system anyone can use and that can be maintained.
